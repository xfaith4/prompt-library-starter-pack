Perform a repository documentation cleanup pass.

Review the README, roadmap, design notes, setup guidance, and related documentation for staleness, inconsistency, duplication, missing context, and unclear wording. Align the documents with the current implementation and intended direction. Preserve important historical decisions where relevant, but remove confusion, ambiguity, and outdated guidance.

Document any remaining gaps that require future follow-up.
