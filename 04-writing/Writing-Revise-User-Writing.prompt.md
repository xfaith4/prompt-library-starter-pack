# Revise User Writing

## Purpose
Improve writing while preserving the user’s intent and core meaning.

## Use when
Use when you want prose improved without losing the original point.

## Prompt
```text
Revise the following writing for clarity, structure, grammar, and tone while preserving the original meaning and intent. Do not overwrite the author’s point of view. Improve readability, tighten weak phrasing, remove unnecessary repetition, and produce a more polished final version.

Where helpful, provide:
1. a clean revised version,
2. a slightly more formal version,
3. and a concise version.
```

## Notes
Good default rewrite prompt.
