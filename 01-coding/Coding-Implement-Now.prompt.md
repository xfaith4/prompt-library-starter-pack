# Implement Now

## Purpose
Approve a reviewed direction and instruct the agent to execute immediately.

## Use when
Use when you agree with the agent and want implementation to begin now.

## Prompt
```text
Approved. Your findings and recommended direction are valid.

Proceed with implementation now. Preserve consistency with existing architecture, standards, and roadmap intent. Keep the change set disciplined, avoid unnecessary unrelated edits, and document any important design decisions, tradeoffs, and follow-up items as part of the implementation.
```

## Notes
Use when urgency is moderate to high and sequencing is already clear.
